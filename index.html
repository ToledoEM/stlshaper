Welcome to STLShaper

Transform any STL directly in your browser — no install, no cloud.

QUICK START

  1. Load an STL file using the file picker.
  2. Choose a deformation type from the panel.
  3. Adjust parameters and click Generate Deformation.
  4. Export your result as STL.

NEW IN 0.9.0 — September 2026

  • Deformation chaining — Compose up to three deformations in the bar along the bottom
  • Perlin noise — Coherent noise field, plus a seed control
  • Reproducible IDW recipes — Settings exports record the control points actually used
  • Test suite — 559 tests guarding against regressions
